# Open this project locally

The v2 source is implemented. Run `./build.ps1 -Test` from this folder to build
and test it, then launch `dist/Stroll.exe`. Keep its config beside the executable.
The original v1 binary remains under `preview-v1/` for reference.

See README.md for usage, V2-PLAN.md for requirements, and docs/TESTING.md for
validation. Optional desktop checks: `./test-desktop.ps1 -Performance`.
