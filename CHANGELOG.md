# Changes

## 0.3.0 - V3 preview - 2026-10-30
- Added bundled J-Yosef as a built-in pet alongside John, S-Yosef and Smooth St Bernard. Mudkip and Dorae are not bundled because of character-rights concerns.
- Set new and unchanged default break backgrounds to #F2EAAA and added a one-click default-colour reset that also clears a background image.
- Added a language picker in the header, visible on all four settings tabs, with English and Cantonese (Hong Kong) UI translations.

## 0.2.4 preview - 2026-10-24

- Named saved pets and a checkbox list for mixed pets, with 1-5 pets on screen.
- John, S-Yosef and Smooth St Bernard bundled; imported Yosef is named J-Yosef.
- Delete saved or bundled pet entries; restore built-ins when wanted.
- One duration slider controls fade-in and fade-out; countdown follows fade-in.
- Rounded, draggable reminder with saved, bounded placement.
- Shared decoded artwork and animation timing keep duplicate copies lightweight.
- Start shortcut support and a setup helper; shortcut launches reuse the running app.

### Known limits

This is an unsigned Windows preview. Start-menu All apps listing/pinning remains
unverified in the affected desktop session, even when shortcut metadata validates.
Use Timing > Add to Start menu or double-click Add-Stroll-to-Start.cmd from the
extracted app folder to create the shortcut in your normal Windows session.
Physical sleep/wake, startup and mixed-DPI monitor acceptance checks remain.
Settings and imported pets are stored on each computer; they are not in this ZIP.
