JOHN — STROLL PET 3

John is the second pet with a soft white mane added around his neck.

IMPORT INTO STROLL
1. Extract this ZIP.
2. Open Stroll settings, then Pet & path.
3. Choose Upload pet and select John-walking.gif.
4. Choose Upload jump and select John-jumping.png.
5. Set Pet name to John.
6. Preview break, then Save settings.

Import the walking file first; uploading a new pet clears its old jump file.
John-standing.png is the static alternative. The app can move this image
with gentle bobbing instead of cycling through walking poses.

The four-pose source sheet and individual walking PNGs are included.
The animation loops through walk A, passing, walk B, passing.
The jump file is a separate pose; Stroll moves it along the hop arc.

Artwork created with the built-in OpenAI image-generation tool by editing
the second pet's sprite sheet. The full editing prompt is in PROMPT.txt.
