STROLL — SECOND PET: SMOOTH-COAT ST BERNARD

A round, short-haired cartoon St Bernard inspired by your plush reference.

IMPORT INTO THE EXISTING APP
1. Extract this ZIP.
2. Open Stroll settings, then Pet & path.
3. Under Walking image / GIF choose Upload pet and select walking.gif.
4. Under Jump image / GIF choose Upload jump and select jumping.png.
5. Give your pet a name, choose its edges, Preview break, then Save settings.

Import the walking file first: importing a new pet clears the old jump file.
The app moves/rotates the walking GIF along your chosen path and animates
its jump pose along the hop arc when opposite edges are selected.

FILES
walking.gif       Transparent looping walk, ready to import.
jumping.png       Transparent jump pose, ready to import.
standing.png      Static alternative if you prefer gentler movement.
walk-a.png        Individual walk pose A.
walk-b.png        Individual walk pose B.
walk-passing.png  Individual passing pose.
sprite-sheet.png  Full generated source sheet.
PROMPT.txt        Generation prompt and reference roles.

The artwork was generated using the built-in OpenAI image-generation tool,
using the original Stroll pet as a style reference and the supplied plush
photos as appearance references. The supplied photos are not in this ZIP.
The app and its existing default pet are unchanged.
