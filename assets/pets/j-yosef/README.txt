J-YOSEF — SMALL NECK RUFF UPDATE

IMPORT INTO STROLL
1. Extract this ZIP.
2. Open Stroll settings, then Pet & path.
3. Choose Upload pet and select J-Yosef-walking.gif.
4. Choose Upload jump and select J-Yosef-jumping.png.
5. Set Pet name to J-Yosef.
6. Preview break, then Save settings.

Upload the walking file first; importing a new pet clears its old jump file.
