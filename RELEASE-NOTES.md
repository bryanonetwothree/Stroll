Stroll v0.2.4 Windows preview

Download Stroll-v0.2.4-Windows-portable.zip below (not GitHub's Source code ZIP),
extract it to a permanent folder on your laptop, then launch Stroll.exe. Keep
Stroll.exe.config beside it. Exit v1 from its tray menu before starting v2.

V2 adds named saved pets, mixed-pet checkboxes, deletion and restore, 1-5 pets,
a shared fade-duration slider, and a draggable rounded reminder. No browser
runtime, installer, account, network requests or third-party application packages.

This is an unsigned preview. Start-menu listing/pinning remains unresolved in
one tested desktop session; the Add-Stroll-to-Start.cmd helper runs registration
in your normal Windows session. Physical sleep/wake and mixed-DPI checks remain.
Your desktop's imported pets and settings are not included or synced to the laptop.
